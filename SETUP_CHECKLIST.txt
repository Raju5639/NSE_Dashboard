========================================
TROUBLESHOOTING QUICK REFERENCE
========================================

PROBLEM: OI Spurts tab shows "Could not load OI Spurts data"
SOLUTION:
  1. Check: chromedriver --version (must work)
  2. Install ChromeDriver from https://chromedriver.chromium.org/
  3. Place in C:\Windows\System32\
  4. Restart Streamlit

PROBLEM: "Module not found: selenium"
SOLUTION: pip install selenium beautifulsoup4

PROBLEM: First load takes very long (>1 minute)
SOLUTION: This is normal if computer is slow or internet is slow

PROBLEM: OI Spurts shows empty table
SOLUTION:
  1. Wait another 15 seconds (still loading)
  2. Click "🔄 Refresh OI Spurts"
  3. Check NSE website manually (might be down)

PROBLEM: Error "chromedriver not found"
SOLUTION: Add Chrome folder to PATH environment variable
