========================================
HOW TO USE THE OI SPURTS FEATURE
========================================

STEP 1: Install Dependencies

pip install -r requirements.txt

This installs Selenium and BeautifulSoup4

STEP 2: Install Chrome & ChromeDriver

Required for browser automation:

a) Download Chrome:
   - Go to: https://www.google.com/chrome/
   - Install in default location

b) Download ChromeDriver:
   - Go to: https://chromedriver.chromium.org/
   - Match your Chrome version
   - Download and extract

c) Place ChromeDriver:
   - Option 1: C:\Windows\System32\ (easiest)
   - Option 2: Project folder
   - Option 3: Add to PATH environment variable

d) Verify:
   - Type: chromedriver --version
   - Should show version number

STEP 3: Run Dashboard

streamlit run app.py

STEP 4: Use OI Spurts Tab

- Navigate to "📊 OI Spurts" tab
- Wait for data to load (15-30 seconds first time)
- Subsequent loads use 2-minute cache
- Click "🔄 Refresh OI Spurts" to force reload
- Click "📥 Download as CSV" to export

========================================
WHY THIS APPROACH?
========================================

OTHER OPTIONS CONSIDERED:

1. Direct API Endpoint ❌
   - Tested 15+ endpoints
   - None provide OI Spurts with historical data
   - NSE doesn't expose this as JSON API

2. nsepython Library ❌
   - Doesn't have OI Spurts functions working
   - Limited to basic option chain data
   - Functions return errors/empty results

3. Database Cache ⚠️
   - Could store historical data
   - Requires users to consent to storage
   - Need to build infrastructure

4. Web Scraping (Selenium) ✅ CHOSEN
   - Direct from source (NSE website)
   - Always matches website exactly
   - Reliable conversion to structured data
   - Handles JavaScript rendering
   - Graceful error handling
   - Clear to user: "This data comes from NSE website"

========================================
SUPPORT & MAINTENANCE
========================================

If OI Spurts stops working:

1. First check:
   - Is NSE website accessible? (Manual check)
   - Is Chrome installed and working?
   - Is ChromeDriver in PATH?

2. Likely causes:
   - NSE website redesigned (most common)
   - Chrome/ChromeDriver version mismatch
   - Network connectivity issues

3. Solutions:
   - Update ChromeDriver to latest version
   - Check NSE website layout hasn't changed
   - Verify internet connection

4. Fallback:
   - Tabs 1 & 2 (Sector & Stock) always work
   - Use API-based data instead
   - OI Spurts is enhancement, not critical
